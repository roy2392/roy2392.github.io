## 🚀 Quick Start

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Git (for cloning and contributions)
- Text editor (VS Code, Sublime Text, etc.)

### Local Development Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/roy2392/roy2392.github.io.git
   cd roy2392.github.io
   ```

2. **Open locally**
   ```bash
   # Option 1: Open index.html directly in your browser
   open index.html
   
   # Option 2: Use a local server (recommended)
   python -m http.server 8000
   # Then visit http://localhost:8000
   ```

3. **Make your changes**
   - Edit HTML, CSS, or JavaScript files
   - Add new project images to the `images/` directory
   - Update project links and descriptions in `index.html`

### 📦 Project Structure
```
roy2392.github.io/
```

## 🌐 Deployment

This portfolio is automatically deployed using **GitHub Pages**:

1. **Automatic Deployment**: Any push to the `main` branch automatically deploys to [https://roy2392.github.io](https://roy2392.github.io)

2. **Custom Domain** (Optional): You can configure a custom domain in the repository settings

3. **HTTPS**: GitHub Pages provides free SSL certificates for secure connections

### Manual Deployment Steps
1. Ensure all changes are committed and pushed to the `main` branch
2. Go to repository **Settings** → **Pages**
3. Select **Deploy from a branch** → **main** → **/ (root)**
4. Your site will be available at `https://[username].github.io`
