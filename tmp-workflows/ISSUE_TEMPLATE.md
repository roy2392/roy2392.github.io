# 🐛 Issue Templates for Roey Zalta's Data Science Portfolio

> **Note**: These issue templates should be moved to `.github/ISSUE_TEMPLATE/` directory for GitHub to automatically use them. Since automated tools cannot edit the `.github/workflows/` directory directly, these templates are provided in the `tmp-workflows/` directory for manual migration.

## 📋 Available Issue Templates

This repository provides three types of issue templates to help maintain a professional and organized collaboration environment:

1. **🐛 Bug Report** - Report issues with the portfolio website
2. **💡 Feature Request** - Suggest new features or improvements
3. **📊 Project Suggestion** - Propose new data science projects to showcase

---

A clear and concise description of what actually happened instead.

## 📁 Directory Structure

When moving these templates to the `.github` directory, use the following structure:

```
.github/
└── ISSUE_TEMPLATE/
    ├── bug_report.md
    ├── feature_request.md
    └── project_suggestion.md
```

## 🔧 Setup Instructions

### Manual Migration Steps

1. **Create the directory structure**:
   ```bash
   mkdir -p .github/ISSUE_TEMPLATE
   ```

2. **Copy the template files**:
   ```bash
   cp tmp-workflows/bug_report.md .github/ISSUE_TEMPLATE/
   cp tmp-workflows/feature_request.md .github/ISSUE_TEMPLATE/
   cp tmp-workflows/project_suggestion.md .github/ISSUE_TEMPLATE/
   ```

3. **Remove the temporary directory** (optional):
   ```bash
   rm -rf tmp-workflows/
   ```

4. **Commit the changes**:
   ```bash
   git add .github/ISSUE_TEMPLATE/
   git commit -m "Add issue templates for bug reports, feature requests, and project suggestions"
   git push origin main
   ```

### GitHub Integration

Once the templates are in the correct `.github/ISSUE_TEMPLATE/` directory:

- GitHub will automatically detect and use these templates
- Users will see template options when creating new issues
- Templates will be available in the issue creation dropdown
- Each template includes appropriate labels and assignees
